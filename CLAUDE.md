We are building a WP plugin to enable MCP for WP site to connect that site with all popular AI agent like Claude, Cursor, Codex, Antigravity, OpenClaw, OpenCode, Deepseek, command code etc so that we can do anything in WP site like creating, deleting, updating, etc posts/pages/CPTs, etc.

Existing plugins for inspiration:
https://github.com/awesomemotive/wpvibe-ai-mcp
https://github.com/bilalnaseer/wsp-wordpress-mcp

What's different approach for this:
- make it very simple and easily understood to the users so that a non-tech person easily can connect his/her wp site with AI agent
- a better UI/UX for the users
- a clear and clean guide to connect the site with a few clicks
- any missing features
- all possible improvements
